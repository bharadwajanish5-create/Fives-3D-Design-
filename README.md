# FiveS Digital — 3D Homepage Design

Interactive UI/UX design prototype for the fivesdigital.com homepage.

- **Live preview:** `index.html` (served by GitHub Pages)
- **Source:** `source/` — React, React Three Fiber, Tailwind CSS, GSAP

All copy and numbers live in `source/src/data/site.ts`.

## Run the source locally
```bash
cd source
npm install
npm run dev          # local preview
npm run build:single # rebuilds the one-file index.html in dist-single/
```
